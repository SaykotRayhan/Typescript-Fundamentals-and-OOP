# Assignment Overview

This assignment was about building problem-solving skills using TypeScript and Object-Oriented Programming. I worked through eight problems and each one helped me get better at using basic types, optional parameters and default parameters. I also got practice with union types and how to narrow down types safely in my code. I used readonly tuples. Started to work with generics, which made my functions more flexible. Among the topics, generics trouble the most. Then learned how to use rest parameters to handle inputs and how to define interfaces and classes properly. I explored the OOP concept inheritance and the use of access modifiers like public, private and protected to control how properties and methods are accessed.

I also practiced programming using Promises and worked with async functions to handle errors effectively. All the solutions were written in one file called `solutions.ts`. This helped me keep everything easy to follow. At the end of this assignment I felt more confident, in writing code that is type-safe, reusable and well-structured. The hands-on experience really helped to understand TypeScript fundamentals.
